# Festivals, sections S2 à S8, version 1

Version mise de côté le 6 octobre 2026, remplacée par un contenu plus
court (le hero est resté) : pour qui, les six postes, les cinq contraintes
(autorisations, sécurité, météo, budget, bénévoles), ce qui se vérifie,
les moyens techniques, onze questions, l'appel final.

`Sections.tsx` reprend les composants et leurs données ; `sections.css`
commence au filet de titre de S2 et va jusqu'à la fin de festival.css
d'alors (blocs Mouvement réduit, Tablette et Téléphone compris).

Ce dossier est hors de `src` : il n'est ni compilé ni publié.
