# Mariage, S4 « Comment ça se passe », version 3 (la frise)

Version mise de côté le 1er octobre 2026 : frise de gauche à droite faite
de trois lignes, une par formule, les étapes en alternance au-dessus et
au-dessous. Le CSS contient la variante pleine largeur (50px du bord).

Pour la remettre : remplacer le bloc S4 du composant et le bloc
« S4 · Le déroulé » de `src/styles/mariage.css` par ces fichiers ; dans
`src/components/apparition.ts`, lister `'.voies'` et
`'.frise-mariage__etape'` (à la place de `'.planning__etape'`). Rien dans les blocs Tablette et Téléphone.

Ce dossier est hors de `src` : il n'est ni compilé ni publié.
